<p align="center">
Real-Time Multi-User Communication System using Java, GUI, Threads & Socket Programming
</p>

---

## 🚀 Overview

Chat Application is a Java-based desktop application designed to enable seamless real-time communication between multiple users through an interactive graphical interface. The system provides instant message delivery, supports multiple users simultaneously, and demonstrates practical implementation of Object-Oriented Programming concepts.

This project combines Java GUI development, multithreading, and socket programming to create a responsive and efficient communication platform.

## ▶ How To Run

### Step 1: Open CMD inside project folder

```cmd
cmd
```

### Step 2: Compile Java files

```cmd
javac Server.java
javac Client.java
```

### Step 3: Run Server

```cmd
java Server
```

Output:

```text
Server started...
```

### Step 4: Open another CMD and run client

```cmd
java Client
```

Run multiple client windows for testing.
